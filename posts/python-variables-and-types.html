基础应用：第一个测试用例

python
import requests

def test_api():
    resp = requests.get("https://httpbin.org/get", params={"name": "test"}, timeout=10)
    assert resp.status_code == 200
    data = resp.json()
    assert data["args"]["name"] == "test"
    print("基础接口测试通过 ✓")

项目进阶：pytest + fixture + 参数化 + 报告

python — conftest.py
import pytest, requests

@pytest.fixture
def api():
    return requests.Session()

@pytest.fixture
def user():
    return {"username": "test@example.com"}
python — 参数化测试
import pytest

@pytest.mark.parametrize("code", [200, 301, 404, 500])
def test_status(api, code):
    resp = api.get(f"https://httpbin.org/status/{code}", timeout=5)
    assert resp.status_code == code

Python 里的变量：不用声明，直接赋值

在 Java 里，你得写 int x = 10;，先声明类型再赋值。在 Python 里，直接写 x = 10 就行了。Python 的变量是「标签」，贴到值上，不占内存。同一个变量名可以贴到不同类型的值上：

python — 变量赋值
# 同一变量，不同类型，完全合法
x = 10          # x 是 int（整数）
x = "hello"     # x 现在是 str（字符串），int 被丢掉了
x = [1, 2, 3]   # x 现在是 list（列表）

# 查看变量的类型
print(type(x))   # <class 'list'>

# 同时赋值（解包）
a, b, c = 1, 2, 3
print(a, b, c)    # 1 2 3

# 变量交换（不用临时变量）
a, b = b, a      # a 和 b 的值交换了
print(a, b)      # 2 1

Python 变量没有「类型」，只有「值」有类型。变量只是贴在值上的「标签」，你随时可以把标签撕下来贴到别的值上。这和 Java/C 的「变量有类型」完全不同。

六大基本类型：测试数据的主力

python — 基本类型一览
# 1. int（整数）—— 订单号、数量、状态码
order_id = 100234
status_code = 200

# 2. float（浮点数）—— 金额、比例、响应时间
price = 99.99
response_time_ms = 156.3

# 3. str（字符串）—— 用户名、邮箱、URL
username = "test_user"
email = "test@example.com"
url = "https://api.example.com/orders/100234"

# 4. bool（布尔）—— 判断条件
is_valid = True
has_permission = False

# 5. None —— 表示"空"、"没有值"
result = None  # 还没有结果
error_message = None  # 没有错误

# 6. 容器类型 —— list / dict / tuple / set
users = ["alice", "bob", "charlie"]     # list（有序、可改）
config = {"env": "test", "timeout": 10}  # dict（键值对）
coordinates = (10.5, 20.3)               # tuple（有序、不可改）
unique_ids = {101, 102, 103}            # set（无序、去重）

None 不是 0，也不是空字符串

这是测试工程师最容易踩的坑：

python — None 的陷阱
print(None == 0)          # False！None 不等于 0
print(None == "")         # False！None 不等于空字符串
print(None is None)       # True（用 is 判断 None，不用 ==）
print(None == None)       # True（但推荐用 is）

# 接口返回"没有数据"时，通常返回 None，不是 0 也不是 ""
result = call_api("/api/data")
if result is None:
    print("接口没返回数据")
else:
    print(f"数据：{result}")

测试断言时，判断「没有值」用 is None，不要用 == 0 或 == ""。接口返回 null 在 Python 里是 None，不是 0。

字符串格式化：f-string 最常用

测试脚本里要打印日志、拼 URL、构造请求头，字符串格式化是基本功。Python 3.6+ 推荐用 f-string（最简洁）：

python — 字符串格式化
# f-string（最推荐，直接写变量名）
user_name = "张三"
order_id = 100234
price = 99.99

# 拼 URL
url = f"https://api.example.com/orders/{order_id}"
print(url)   # https://api.example.com/orders/100234

# 拼日志
print(f"[测试] 用户 {user_name} 的订单 {order_id} 金额 {price:.2f}")
# [测试] 用户 张三 的订单 100234 金额 99.99

# f-string 里还能写表达式
count = 5
print(f"共 {count * 2} 条用例" + " 执行完毕")  # 共 10 条用例 执行完毕

# 传统格式（老代码里常见，认识一下）
print("订单 %d 金额 %.2f" % (order_id, price))
print("订单 {} 金额 {:.2f}".format(order_id, price))

常见类型错误：TypeError 和 ValueError

写测试脚本时，最常遇到的两个类型错误：

python — 类型错误示例
# 1. TypeError：类型不匹配（"字符串 + 整数"）
try:
    result = "订单号：" + 100234   # str + int，报错
except TypeError as e:
    print(f"类型错误：{e}")
    # 类型错误：can only concatenate str (not "int") to str
    # 修正：result = f"订单号：{100234}"

# 2. ValueError：值不合法（"把'abc'转成整数"）
try:
    number = int("abc")   # 字符串 "abc" 不是合法数字，报错
except ValueError as e:
    print(f"值错误：{e}")
    # 值错误：invalid literal for int() with base 10: 'abc'
    # 修正：先判断再转换
    user_input = "abc"
    if user_input.isdigit():
        number = int(user_input)
    else:
        print("输入不是数字")

测试脚本里，接口返回的数据「看起来像数字」但其实是字符串（"100" 而不是 100），直接当数字用会报 TypeError。写断言前先确认类型：print(type(data))。

案例：测试数据准备

把上面学到的变量、类型、f-string 串起来，写一段「测试数据准备」代码：

python — 测试数据准备
import random
import string

def generate_test_user():
    """生成一个测试用户数据（模拟接口返回）"""
    # 生成随机用户名（6 位字母）
    username = ''.join(random.choices(string.ascii_lowercase, k=6))

    # 生成随机邮箱
    email = f"{username}@test.example.com"

    # 生成随机手机号（11 位）
    phone = "1" + str(random.randint(1000000000, 9999999999))

    # 生成随机年龄（18~60）
    age = random.randint(18, 60)

    # 组装成字典（模拟接口 JSON 响应）
    user_data = {
        "username": username,
        "email": email,
        "phone": phone,
        "age": age,
        "is_active": True,
        "avatar": None,  # 没有头像，用 None 表示
    }
    return user_data

# 生成 5 个测试用户
test_users = [generate_test_user() for _ in range(5)]

# 打印结果
for user in test_users:
    print(f"用户：{user['username']}  邮箱：{user['email']}  年龄：{user['age']}")

# 检查数据类型
assert all(isinstance(u["age"], int) for u in test_users)   # 年龄必须是 int
assert all(u["avatar"] is None for u in test_users)          # 头像都是 None

这段代码用到了：随机数据生成（random）、f-string 拼接邮箱、字典构造测试数据、列表推导式批量生成、断言检查数据类型。这就是测试工程师写「测试数据准备」代码的日常。

记住三条：① 变量不用声明，直接赋值；② 判断「没有值」用 is None；③ 打印/拼接字符串用 f-string，最简洁。
