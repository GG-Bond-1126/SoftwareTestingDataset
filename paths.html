学习路径

124 篇笔记按目标重新编排成 4 条线。不必全读，挑一条按顺序走完，比随机跳读有效得多。

路径 1 · 四周入门：从环境到第一条自动化用例

适合刚转自动化或刚开始读这个站的人。按顺序读完，能独立写出一条稳定的端到端用例。

  1. Python 变量与类型先把语法补齐，不用学完整个 Python
  2. Python 流程控制if/for/while 在测试脚本里的真实用法
  3. 函数与参数把重复步骤抽成可复用函数
  4. Git 基础提交、分支、回滚，测试代码也要版本管理
  5. Playwright 入门装环境、跑通第一个浏览器脚本
  6. 等待策略自动化不稳定的头号原因
  7. 元素定位CSS 与 XPath 怎么选、为什么绝对路径会烂
  8. 端到端测试设计从用户场景切用例，而不是从页面切

路径 2 · Web 自动化进阶：框架与稳定性

已经能写脚本，但用例一多就乱、一上 CI 就飘。这一条路径解决结构与稳定性。

  1. 框架分层架构用例层到驱动层怎么切
  2. Page Object 实践页面对象该返回什么、断言放哪
  3. 常见坑清单幽灵元素、多窗口、Cookie 共享
  4. 调试与取证失败现场要留下什么
  5. 视觉回归样式错位这类问题怎么自动发现
  6. 测试报告从跑通了到可汇报
  7. 接入 CI/CDPR 门禁、分片与缓存
  8. 性能压测QPS、分位与拐点怎么读

路径 3 · AI 测试落地：从需求到回归

这条路径按真实工作流排序：拆需求 → 出测试点 → 出用例 → 造数据 → 圈回归 → 定位缺陷 → 度量。

  1. AI 应用测试入门不确定输出下断言方式怎么变
  2. AI 拆需求把 PRD 读成可测的需求点
  3. AI 生成测试点输出可评审的检查项
  4. AI 生成业务用例按用户场景组织
  5. AI 生成接口用例按字段、状态码、边界组织
  6. AI 设计测试数据从字段约束到数据集
  7. AI 圈回归范围用改动影响面替代全量回归
  8. AI 缺陷根因分析用上下文缩小排查面
  9. AI 提效度量别只看生成了多少条用例

路径 4 · 大模型应用怎么测

面向做 LLM 产品测试的人：提示词、幻觉、评测、RAG、安全，一条线打通。

  1. Prompt 测试版本快照与全量回归
  2. 幻觉测试事实校验与引用可追溯
  3. 大模型评测评测集、指标与 LLM 裁判
  4. RAG 测试召回、排序与拒答
  5. 模型测试鲁棒性、一致性与偏见
  6. 安全测试注入、越权与数据泄露
  7. 上线与监控Prompt 回归门禁
  8. Agent 测试进阶多步任务与工具调用
